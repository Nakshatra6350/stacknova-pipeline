Privacy policy

StackNova Publisher · last updated 16 October 2026

YouTube API Services

StackNova Publisher uses YouTube API Services. By using it you agree to be bound by the YouTube Terms of Service, and your information is also handled under the Google Privacy Policy (https://policies.google.com/privacy).

Who uses it

StackNova Publisher is a personal tool used only by the owner of the StackNova YouTube channel (@StackNovaDev) to manage that channel. It does not offer sign-in to anyone else and does not access any other user's account.

What it accesses

  • The owner's own YouTube channel, through the YouTube Data API, to upload the owner's videos and set their titles, descriptions, thumbnails, captions, playlists and publishing schedule.
  • The owner's own channel analytics, through the YouTube Analytics API, to produce a weekly report for the owner.

What it stores, and where

Only the IDs and publishing status of the channel's own videos, and aggregate analytics of the channel, kept in the project's GitHub repository for the weekly report. It stores no data about viewers or any other user, uses no cookies and does not track anyone. Credentials are kept as encrypted repository secrets and are never published.

Sharing

No data is sold or shared with anyone. The use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Retention and deletion

Analytics data kept for the weekly report is refreshed from the API and not kept longer than 30 days unless the owner has re-fetched it. Video IDs and publishing status are kept while the videos exist. When access is revoked, or on request, all stored API data is deleted within 7 days, and the stored credentials are removed from the repository secrets.

Revoking access

Access can be revoked at any time through the Google security settings page at https://security.google.com/settings/security/permissions.

Contact

Through the StackNova YouTube channel or the project's GitHub issues.
