# M2 Scenes Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** Render each narration as an animated schematic in the owner's portfolio style, frame-exact, in 16:9 and 9:16, from the visual steps in `episode.yaml`.

**Architecture:** One clock per scene; every property on screen is a function of time. Pure-Python modules (theme, phrase timing, spec, geometry) carry the logic and are tested without Manim; `kit.py`, `flow.py` and `render.py` draw with Manim and are covered by low-resolution render tests.

**Tech Stack:** Python 3.12, uv, Manim Community 0.21.0 (Cairo), PyAV, ffmpeg, pytest.

**Spec:** `docs/superpowers/specs/2026-10-09-m2-scenes-design.md`

**Note on this plan's shape:** unlike the M0 and M1 plans, the Manim code is not reproduced here. Scene code is tuned by looking at rendered frames, so the source files are the single source; this plan fixes the tasks, interfaces, tests and acceptance.

## Global Constraints

- Python `>=3.12,<3.13`; `uv run pytest`, `uv run ruff check`, `uv run mypy src` pass before a task is done.
- `manim==0.21.0` lives in the `scenes` dependency group, declared in conflict with `voice`.
- Manim is imported only inside `kit.py`, `flow.py` and `render.py`.
- No colour or font name in scene code: both come from `config/themes.yaml`.
- The clock's driver mobject is the first mobject added to every scene.
- Portrait content stays inside x 60-1020, y 260-1040; landscape inside x 160-1760, y 110-970.
- A render whose frame count differs from `round(duration * 30)` fails.
- Rendered media stays out of git and out of workflow artifacts.
- Work on branch `m2-scenes`; stage files by explicit path; commit messages end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
